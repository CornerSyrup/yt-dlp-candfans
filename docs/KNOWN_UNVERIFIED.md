# 確認済みの事項と未検証の事項

公開 fixture は、ユーザー提供データから個人やコンテンツを識別できる情報を置き換えたものです。解析に必要な構造と一部の値を保持し、クリエイター情報、本文、メディア URL を差し替えています。元のレスポンスとバイト単位で一致するものではありません。テスト用のフィールド値、lookup のレスポンス構造、絶対 URL のサムネイル、エラーケースには、別途 synthetic（合成データ）であることを明記しています。[fixture の説明](../tests/fixtures/README.md)も参照してください。

| サムネイル | ユーザーは `974904` の画像が `https://video.candfans.jp/user/1422016/post/974904/thumbnail.jpg` にあり、API の相対パスと一致することを確認しています | `/user/<user_id>/post/<post_id>/thumbnail.jpg` に一致する相対パスは、既定でこの HTTPS origin に接続します。この origin の最初の根拠は、ユーザーが確認した 1 投稿です。その後、ローカル環境で単一投稿とプロフィール内 9 投稿の実際の CDN サムネイルをダウンロードしました。すべての投稿、ホスト、live API を検証したわけではありません。API の絶対 HTTPS URL も受け入れます。ほかの相対パスやホストには、確認済みの `thumbnail_origin` を指定できます。origin にパス、クエリ、フラグメント、ユーザー名やパスワードは指定できません。 |

公開の報告には、必要最小限の匿名化した JSON とバージョン情報だけを含めてください。新しい API の根拠を追加する際は fixture とテストも更新し、合成データのフィールドや URL を確認済みの仕様として扱わないでください。実際の Cookie、アカウント情報、署名付き URL、有料コンテンツ、バックエンドの trace はコミットしないでください。
