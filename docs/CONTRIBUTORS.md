# 貢献者

## 作者・メンテナー

**CornerSyrup（Klein）** が要件、提供データ、動作確認および保守方針を担当します。

## OpenAI Codex による実装支援

OpenAI Codex は、extractor、API フィールドの検査とエラー処理、遅延ページ送り、手動 Cookie 対応、メタデータとサムネイル処理、オフライン単体テスト、Windows 公式 EXE とサムネイル埋め込みの検証、CI/CD、ZIP のパッケージングおよび文書作成を支援しました。

要件、コンテンツへのアクセス・ダウンロード権限の判断、および今後の保守に関する決定は作者が行います。
